#     host     a parent, a host submodule or a driver: it imports no MLX name (not mlxf, a generated module or a
#              device module) and compiles without the library
#     glue     a submodule of a toy class named <host unit>_mlx, the only files of the class that import mlxf or a
#              device module, and only inside their one #ifdef USE_MLX branch (stubs under #else)

#              module of a toy class (mlxf_toy_device_work, the opaque type it extends, excepted; a device module
#              <stem>_mlx may import <stem>, its own host half: the device engine fills the host record)
