# The C signature classes of mlx-fortran's helpers: one line per class, its Fortran name and one mlx-c function
# that has the signature. scripts/gen_mlxc_bindings.py writes each class as an abstract interface of the module
# mlxf_c_signatures (build/gen/mlxf_c_signatures.f90) with the characteristics of that function's prototype in the
# headers linked: a class is the header's signature, never a hand copy, and the build fails when the function is
# gone or a helper is handed a function whose signature moved away from its class. A helper takes the functions of
# its class as procedure(<class>); a new class is a new line here, named for what its helper does.
